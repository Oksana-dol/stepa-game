Стёпа играет в слова — офлайн-пакет

macOS
1. Откройте файл «Запустить-Стёпу.command» двойным щелчком.
2. Откройте адрес http://localhost:4173/.
3. Для остановки вернитесь в окно запуска и нажмите Ctrl+C.

Windows
1. Откройте файл «Запустить-Стёпу.bat».
2. Откройте адрес http://localhost:4173/.
3. Для остановки закройте окно запуска.

Интернет не нужен: изображения, звук и интерфейс находятся внутри этой папки.
Запуск через file:// не поддерживается — используйте файл запуска.
